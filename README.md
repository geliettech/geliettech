# 🌐 Personal Portfolio Website

A modern, responsive portfolio website built to showcase my skills, projects, experience, and journey as a Developer. The portfolio highlights my expertise in building fast, accessible, and user-friendly web applications while providing an easy way for recruiters, clients, and collaborators to connect with me.


---

## ✨ Features

- Modern and responsive UI
- Smooth scrolling navigation
- Professional hero section
- About Me section
- Skills showcase
- Featured projects with live demos
- Work experience
- Contact section
- Resume download
- Mobile-friendly design
- Fast page loading
- SEO-friendly structure

---

## 🛠️ Tech Stack

### Frontend

- React.js
- JavaScript (ES6+)
- Tailwind CSS

### Deployment

- Vercel
